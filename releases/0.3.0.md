# Apace 0.3.0

First stable release of the Glory-maintained Apace engine.

- Integrates reviewed upstream Blitz changes through `e5929f9e`, including inline layout, writing modes, DOM invalidation, stylesheet handling, CSS painting and runtime updates.
- Retains the maintained resource limits, incremental retirement, focus and form-state fixes, placeholders, top layers and bounded native IME behavior.
- Uses Stylo 0.23.0 and Selectors 0.42.0 from crates.io, including `-webkit-text-fill-color` support without a forked Git dependency.
- Coordinates with Takia 0.15.1 and Wingy 0.31.1 using exact registry requirements for published consumers.
- Requires Rust 1.95 and uses Cargo resolver 3. The published family uses registry dependencies; consumers need no global Cargo patches.

Validation and publication are gated by repository CI. Platform checks establish compilation and regression-test evidence; they do not claim unperformed real-device IME or accessibility acceptance.
