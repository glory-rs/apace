# Apace 0.4.0

Wheel events carry the input source and gesture phase from Wingy through the
shell, DOM and native Dioxus event data. When constructing an
`ApaceWheelEvent`, set both `source` and `phase`. For a mouse wheel without
gesture boundaries, use `Wheel` and `Moved`.

Default trackpad scrolling follows the gesture's dominant axis. Momentum
inherits the preceding finger gesture, while event handlers receive the
original deltas. Physical wheel events continue to scroll both axes.

Layout cache reads use Takia 0.16.0 through shared node references and avoid
allocating layout data on a miss. Native windows use Wingy 0.31.2.
